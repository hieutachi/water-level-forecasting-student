Tại sao R² > 0.998?

Dữ liệu MIKE11 tuân theo phương trình Saint-Venant → dynamics mượt, ít noise. R² cao là tính chất của dữ liệu, không phải model giỏi.

// Saint-Venant 1D (MIKE11 giải) ∂A/∂t + ∂Q/∂x = q // continuity ∂Q/∂t + ∂(Q²/A)/∂x + gA·∂h/∂x = -gA·Sf // momentum

💡 Bài học rút ra cho Sinh viên

6 bài học từ hành trình DATN → Paper quốc tế

1. Feature Engineering > Model

Linear Regression thắng ensemble ở t+1, t+3. Đầu tư feature engineering hiệu quả hơn tìm model phức tạp.

2. Temporal Split — NEVER Random

Dữ liệu thời gian phải chia theo thời gian. Random split gây data leakage → kết quả quá lạc quan.

3. Surrogate Framing — Honest Scope

Phải trung thực về mô hình học cái gì. ML học từ simulator ≠ dự báo thực địa.

4. R² cao cần Context

R² > 0.998 là do dữ liệu mượt (MIKE11), không phải model giỏi. Always report alongside MAPE.

5. Imbalance = Wilson CI + Counts

9/722 Exceedance → Wilson CI [0.35, 0.88] quá rộng. Luôn báo sample counts cho minority class.

6. Đọc Reviewer Response

Thư trả lời reviewer là tài liệu quý giá nhất. Học cách phản biện, cải thiện, và viết khoa học.
